# Heritage Healthcare — Brand Refresh V2

This website package has been reworked around the supplied Heritage Healthcare logo and the supplied 2026 brand guidelines.

## Brand assets used

- `assets/heritage-logo.png` — cropped transparent version of the supplied master logo.
- `assets/heritage-logo-dark.png` — dark-background treatment created from the supplied logo.
- `assets/heritage-logo-tight.png` — compact version used for the browser icon.
- `assets/brand-imagery/care-hero.jpeg` — imagery extracted from the supplied brand guidelines, page 10.
- `assets/brand-imagery/care-team.jpeg` — imagery extracted from the supplied brand guidelines, page 11.

## Brand palette

The supplied guidelines specify:

- Primary purple: `#5c4d9b`
- Deep purple: `#332173`
- Cyan: `#34bbda`
- Pink: `#f3a4bb`
- Light grey: `#f1f3f3`
- White: `#ffffff`
- Black: `#000000`

The website uses these as the core interface colours rather than the previous dark green palette.

## Typography

The guidelines specify Tenso Light for headlines, Tenso Medium for introductory paragraphs/body copy, Tenso Light for body copy and Tenso Italic for quotes. The CSS therefore prioritises Tenso where it is installed and uses a clean sans-serif fallback stack for web environments where the font is not locally available.

## Design direction

The redesign uses:

- Large, airy white space
- Purple-led navigation and hero areas
- Cyan interaction accents
- Pink used sparingly for warmth and emphasis
- Rounded cards and restrained shadows
- Real care imagery from the supplied brand material
- The master logo as the primary website identity
- Strong mobile layouts
- The existing multi-page navigation and individual location pages
- The existing postcode-routing/contact functionality
- The existing CRM prototype

## Important

The logo in this package is based directly on the supplied JPG and is provided as a transparent PNG for reliable browser rendering. For a final production site, an original SVG/AI/EPS master logo should be used if available to ensure perfect scaling at every size.
