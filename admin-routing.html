How this V1 CMS works

Head Office can create and publish content here. Published content is rendered into the public Blog and Care Hub pages. This V1 stores content in the browser so you can fully test the workflow on the prototype. For the production system, the same interface should be connected to a secure shared database/API so every visitor sees new content immediately and multiple Head Office users can work together.
